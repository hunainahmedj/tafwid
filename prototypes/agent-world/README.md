# Tafwid agent world

A local prototype of an open, low-poly 3D world where sample agents work.
Everything shown is fictional sample data. It never reads Tafwid's private
state or launches workers. The design lives in the
[spec](../../docs/superpowers/specs/2026-10-03-agent-world-design.md).

## Run

Requires Node 20.19+ or 22.12+. From this directory:

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:4174.
