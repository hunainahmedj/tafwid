## Rules

- Follow [the documentation guide](07-meta/documentation-guide.md).
- Before changing behavior, read the relevant [module](04-modules/README.md)
  and [decisions](05-decisions/README.md).
- Task state lives only in the [self-tracked TAF backlog](01-project/backlog.md).
- Preserve the root [contributor instructions](../AGENTS.md), including
  private-state protections and offline test requirements.
- Read [contributing](../CONTRIBUTING.md) for build and release procedures.
- Specs and plans stay in `docs/superpowers/`; they are working documents,
  not substitutes for durable module documentation.
- Never imply a planned dashboard, sample data, or future social feature is
  part of the released plugin.
