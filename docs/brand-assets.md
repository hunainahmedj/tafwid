# Brand assets

The title is **Tafwid**, in Latin letters only. The branching mark represents
one orchestrator delegating work to multiple agents. Charcoal and pale sage
match the existing dashboard. The cover is promotional artwork, not an app
screenshot or a claim that planned backends are implemented.

Assets are bundled in `plugins/tafwid/assets/`: `icon.png` and `cover.png`.
Both were generated with the built-in image-generation tool and visually
reviewed. The cover used the icon as its visual reference. These prompts are
kept for future brand iterations; they are not loaded into worker context.

## Icon prompt

Create a production-ready square app icon for Tafwid, a developer tool that delegates work from one orchestrator to multiple coding agents. Logo-brand asset. One strong minimal geometric mark: a capital T formed by a central vertical stem that branches into three short paths with solid rounded-square terminals, communicating controlled delegation. Optically balanced, distinctive silhouette, bold geometry legible at 24px. Flat pale sage green #D7E4B7 mark on a solid near-black charcoal #171817 square canvas, subtle rounded corners within the canvas if needed. Center mark with generous padding, mark occupying about 60% of canvas. Perfect crisp edges, sophisticated restrained developer-tool identity. No lettering, no wordmark, no Arabic, no mockup, no gradient, no glow, no drop shadow, no extra symbols, no robot, no brain, no starburst. Output a single finished 1024x1024 PNG icon.

## Cover prompt

Create a polished widescreen 16:9 brand cover image for the Tafwid developer-tool plugin. Use the attached icon as the exact visual identity reference: pale sage three-branch delegation mark, rounded-square terminals, near-black charcoal background. The reference is a brand/style reference, not a request to show the square icon screenshot. Layout: confident editorial typography on the left, a large elegantly rendered version of this same branching mark on the right with subtle layered geometric shapes suggesting coordinated worker tasks. Restrained charcoal #171817, sage #D7E4B7 and warm off-white palette matching a dark developer dashboard. Strong negative space and precise alignment. Main title exactly 'Tafwid'. Secondary line exactly 'Delegate work. Keep control.' Small lower-left caption exactly 'Codex orchestrates. Agents deliver.' Nothing else written. Latin letters only. No Arabic, no third-party logos, no fake app screenshot, no robot, no brain, no purple gradient. Quiet premium software identity, crisp and composed, no garish glow. Keep all text well inside generous safe margins. Output single final landscape PNG suitable for a plugin gallery and GitHub README hero.
