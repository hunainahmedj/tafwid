# Processes

The [contribution guide](../../CONTRIBUTING.md) owns development, verification,
and release procedures. The [documentation guide](../07-meta/documentation-guide.md)
owns documentation rules. The [backlog](../01-project/backlog.md) is the
self-tracker: moving an item between its sections changes its status.

Use `codex/` for new development branch names unless the user specifies
another convention. Do not change release versions for documentation-only
work. Review implementation plans before beginning new subsystems under
the applicable skill workflow.
